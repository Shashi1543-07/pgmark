Prerequisites

Component Requirement Notes
Python Version 3.10 or 3.11 Make sure "Add Python to PATH" is checked during install
Git Any recent version For cloning and syncing updates
OS Windows 10/11, Ubuntu Linux, or macOS Designed to operate completely offline on CPU laptops

Step-by-Step Setup Instructions

1

Clone the Repository

Open terminal / PowerShell and clone the project to your local workspace:

git clone <repository-url>
cd pugmark-v0.1.1
2

Create and Activate Virtual Environment

Windows (PowerShell):

python -m venv .venv
.venv\Scripts\activate

Linux / macOS:

python3 -m venv .venv
source .venv/bin/activate
3

Install Required Python Dependencies

Upgrade pip and install all necessary packages:

python -m pip install --upgrade pip
pip install -r requirements.txt
4

Seed Demo Data & Admin Account

Initializes SQLite schema, seeds Pench demonstration reserve (36 stations, 3 cycles, 10 alert scenarios), and creates admin credentials:

python -m tools.seed_demo

(Optional) Set a custom admin password immediately:

python -m tools.emergency_reset_admin admin "Admin@12345"
5

Launch the Edge Server

Option A — One-Click Scripts:

launcher\run.bat       # On Windows
./launcher/run.sh      # On Linux / macOS

Option B — Direct Uvicorn Command:

python -m uvicorn edge.app:app --host 127.0.0.1 --port 7860
6

Open the Web Application

Open any web browser and visit:

http://127.0.0.1:7860

• Username: admin
• Password: Password printed on terminal during seed or set via emergency_reset_admin

Verification & Test Suite

To verify that the database migrations, computer vision pipelines, and REST APIs are working properly:

# 1. Run unit test suite
python -m pytest tests/unit -q --tb=short

# 2. Run live HTTP route integration tests
python -m tests.live.test_routes

# 3. Run alert scenario engine tests
python -m tests.scenarios.test_alert_scenarios
